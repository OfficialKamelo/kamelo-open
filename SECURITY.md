# Security Policy

Kamelo reads what you type into AI chats, so security and privacy reports get priority.

## Supported versions

Only the latest release receives fixes. Please check that you're on the newest version (see `chrome://extensions`, `edge://extensions` or `about:addons`) before reporting.

## Reporting a vulnerability

**Please don't open a public issue for security problems.** Report privately instead:

- via **Security → Report a vulnerability** on this repository (preferred), or
- by email to hello@kamelo.eu.

Examples of what to report:
- any way data leaves the device, or a network request made by Kamelo
- a website that can read text through the extension that it shouldn't see (for example a message handed to a temporary chat or to Private Chat)
- Kamelo running on a site where it shouldn't, or the on-device AI being downloaded without a click
- data from older versions (the vault) that is not deleted after updating

Please include the Kamelo version, the browser and its version, the site, and steps to reproduce. Use made-up data, never real personal data.

## What happens next

- We'll reply within 7 days.
- Once confirmed, we'll work on a fix and keep you updated. Please give us reasonable time to release it before you disclose the issue publicly.
- With your permission, we'll credit you in the release notes.

A personal topic that Kamelo misses, or a notice for an ordinary question, is not a security issue: please open a normal issue for those.
